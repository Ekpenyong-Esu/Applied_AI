\section{Introduction}

This lab covers the basics of machine learning and how to run experiments in a systematic way.
Part~1 is about loading and pre-processing data: my own photo dataset and a multi-digit MNIST
embedding file from a collaborator. Part~2 uses a nearest-neighbour classifier on MNIST to practise
working with datasets and hyperparameters. Part~3 trains SVMs with different kernels on the Iris
dataset, and Part~4 is a larger set of experiments on ten UCI datasets, compared with the results
of \textcite{delgado2014}.

All code is in \texttt{Lab1\_Solution.ipynb} and the \texttt{lab1/} package next to it.
